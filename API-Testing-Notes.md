# API Testing Notes

## What is API Testing?

API Testing is a type of software testing
that verifies APIs for functionality,
reliability, performance and security.

## Types of API Methods

1. GET - Retrieve data
2. POST - Create data
3. PUT - Update existing data
4. PATCH - Partially update data
5. DELETE - Remove data

## API Testing Tools

- Postman
- Swagger
- REST Assured
